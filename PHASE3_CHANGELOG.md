# CareAtlas Phase 3

Patient product layer added on top of Phase 2.

## Added
- Patient dashboard and journey tracker
- Structured case overview and hospital review status
- Treatment plans page with normalized hospital proposal
- Medical documents centre (demo-only, no real uploads)
- Coordinator messaging prototype (browser-only)
- Patient portal navigation shell
- Phase 2 login now opens patient dashboard after demo sign-in
- Responsive patient portal layouts

## Safety / Hosting note
GitHub Pages is static hosting. Phase 3 intentionally does not transmit or persist real passwords, medical files, messages or patient data. Production backend, encrypted storage, authentication, access control and audit trails remain future work.
